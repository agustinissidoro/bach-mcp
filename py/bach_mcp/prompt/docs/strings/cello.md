# Cello

register: 3600–7600
- 3600–5000 (C and G strings): deep and resonant, the bass of the string section
- 5000–6900 (D and A strings): warm and singing; the A string is the cello's melodic voice
- 6900–7600: intense and expressive, high on the A string (thumb position)
expanded_register: 7600–8800 in solo writing (thumb position): thinner, less secure in fast passages. Natural harmonics reach higher (see Harmonics).
transposing: no
clefs: F; Tenor for passages around 6200–7200; G for passages that stay above about 7200
techniques: the string-family techniques (strings/_family.md), plus:
- open strings 3600 4300 5000 5700
- agile in the middle and high registers; fast passages on the C string sound heavier
- double stops: thirds, sixths and octaves (octaves in thumb position); tenths only with an open string
- pizz. rings long in the low register, about 1–2 s

## Harmonics
A natural harmonic is a partial of an open string, played by touching the
string lightly at a node. Partial n sounds at the open string + 1200·log2(n):
2 → +1200, 3 → +1902, 4 → +2400, 5 → +2786, 6 → +3102.

```
string   partial 2     3     4     5     6
3600              4800  5502  6000  6386  6702
4300              5500  6202  6700  7086  7402
5000              6200  6902  7400  7786  8102
5700              6900  7602  8100  8486  8802
```

Partials 2 to 5 are secure, 6 and higher possible on the lower strings. An
artificial harmonic is a stopped note S with a second finger touching above it,
mostly in thumb position: touching a fourth above sounds S + 2400, a fifth
above S + 1902, an octave above S + 1200. Harmonics are soft, pure and glassy.

Write the sounding pitch with "art": "harmonic"; bach plays the written pitch,
so the score sounds right. A harmonic glissando (the finger sliding lightly
along the string) is a fast run of these partials, about 40–80 ms apart.
